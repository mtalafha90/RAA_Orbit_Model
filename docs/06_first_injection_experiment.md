# 06 — First injection experiment [historical]

This document preserves the first uniform-angle injection/recovery pilot for provenance. It was useful for debugging the joint visual/SB2/Gaia-like fit and establishing that an intentionally misspecified photocentre model can accumulate coherent residual mismatch when data are generated with a nonlinear blend response.

The pilot predates the final orbit-convention audit and mission-grounded schedule programme. Its numerical transition values therefore must not be used as manuscript evidence or interpreted as physical Gaia resolution thresholds.

Current scientific interpretation is based instead on:

- the audited orbit conventions (`03`);
- mission-grounded scan schedules (`04`);
- the M0/M1/M2 response-fidelity hierarchy (`12`–`14`);
- frozen result tables under `results/frozen/`.

This file remains only to document the development path and should not be cited as a current experiment result.
