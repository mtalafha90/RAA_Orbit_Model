# Frozen compact results

This directory stores compact numerical products used directly in `sample.tex`.

The large raw synthetic tables are generated by the experiment scripts and are not duplicated here. The frozen tables are recomputed from the completed native full-sky and matched-N=53 outputs.

- `experiment_integrity.csv`: row counts, sky counts, convergence/validity, and transit ranges.
- `full_sky_dr4_beta_separation_summary.csv`: all-sky paired Delta-chi2 summaries over the final native beta/separation grid.
- `native_photocentre_bias_a1.csv`: pooled photocentre parameter biases at a/sigma=1.
- `native_vs_matched_n53_beta025_a1_by_sky.csv`: 46-position native/control comparison at beta_G=0.25, a/sigma=1.
- `native_vs_matched_n53_beta025_boundaries_by_sky.csv`: sampled first-crossing boundaries per sky position.
- `native_vs_matched_n53_boundary_counts.csv`: counts of sky positions at each sampled boundary.
- `native_vs_matched_n53_summary.csv`: one-row headline comparison and correlation summary.
- `full_sky_dr4_scan_geometry.csv`: archived native full-sky geometry diagnostics.
- `matched_n53_scan_geometry.csv`: archived matched-control geometry diagnostics.

These values describe the current Gaussian research surrogate and must not be interpreted as calibrated Gaia angular-resolution thresholds.
