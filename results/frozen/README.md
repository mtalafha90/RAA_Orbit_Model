# Frozen compact results

This directory stores compact numerical products used directly in `sample.tex` and `docs/native_vs_matched_n53_results.md`.

The large raw synthetic tables are generated by the experiment scripts and are not duplicated in repository history. The committed frozen products are recomputed from the completed native full-sky and matched-N=53 outputs.

- `experiment_integrity.csv`: final row counts, sky counts, convergence/validity, and transit ranges.
- `full_sky_dr4_beta_separation_summary.csv`: all-sky paired Delta-chi2 summaries over the final native beta/separation grid.
- `native_photocentre_bias_a1.csv`: pooled photocentre parameter biases at a/sigma=1.
- `native_vs_matched_n53_boundary_counts.csv`: counts of sky positions at each sampled native and matched first-crossing boundary.
- `native_vs_matched_n53_summary.csv`: exact headline native-versus-matched numerical and correlation summary.

The comparison CLI `scripts/compare_native_matched_n.py` regenerates the more detailed 46-position by-sky tables and figures from the raw experiment outputs when those files are present locally.

These values describe the current equal-width Gaussian research surrogate. They must not be interpreted as calibrated Gaia angular-resolution thresholds, and the nominal scanning-law schedules are not actual source-level observation lists.
